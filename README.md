# 🏥 Hospital Emergency Room Dashboard (Excel Project)

This is my **first Excel Data Analysis project**, where I built an **interactive dashboard** for analyzing Emergency Room (ER) data of a hospital. I created this project after learning from **Satish Dhawale sir**, whose guidance helped me understand how to transform raw data into visual stories.

<br>

## 📌 Project Overview

In this project, I analyzed hospital ER data to uncover patterns, trends, and performance indicators. The final dashboard gives insights into patient flow, wait times, satisfaction scores, and more.

### 🔍 Key Performance Indicators (KPIs):

- **Number of Patients:**  
  Total count of ER visits per day with an area sparkline to identify trends.

- **Average Wait Time (Minutes):**  
  Daily average time patients waited to be seen, with trend analysis.

- **Patient Satisfaction Score:**  
  Tracks the average score given by patients to measure service quality.

<br>

### 📊 Charts & Visuals Included:

- **Admission Status:** Number of admitted vs. not admitted patients.
- **Age Group Distribution:** Patients grouped into age categories.
- **Timeliness:** % of patients attended within 30 minutes.
- **Gender Analysis:** Number of male vs. female patients.
- **Department Referrals:** Which departments received most ER referrals.
